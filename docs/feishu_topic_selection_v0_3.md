# 飞书 04 选题挑选台 v0.3

`04 分析与选题` 的主入口不再是普通表格，而是飞书多维表格内的挑选工作区。

## 日常视图

- `今日挑选卡片`：画册视图，用来快速扫选题。
- `今日决策看板`：看板视图，用来按状态推进。
- `证据不足`：聚焦可展示证据和需要补的证据。
- `待学习样本`：查看已做选择、等待学习的样本。
- `今日候选池`：保留表格视图，供排查。

## 卡片应该直接读什么

`今日挑选卡片` 的核心字段是 `卡片速读`。它会把你真正需要判断的信息合并成一段卡片正文：

- 当前状态、建议级别、AI味风险、对应方向
- 一句话 Brief
- 我要做的实验
- 我的工作流痛点
- 验证方式
- 可展示证据和需要补的证据
- 可沉淀资产
- 操作提示

日常不要求打开详情页逐格读。先看 `选题标题` 和 `卡片速读`，然后直接改 `状态`，再点 `选择原因标签`。

## 选择反馈字段

- `卡片速读`：自动生成，专门服务画册卡片阅读，不作为脚本下游判断来源。
- `选择原因标签`：多选，记录为什么推进或放弃。
- `人工一句话判断`：可选，记录一句真实判断。
- `学习状态`：`待学习 / 待确认学习 / 已学习 / 忽略`。学习脚本默认只生成待确认摘要，不会自动影响下一轮主编判断。

## 推荐使用方式

1. 打开 `04 分析与选题 / 今日挑选卡片`。
2. 快速扫每张卡片的标题和 `卡片速读`。
3. 把 `状态` 改成 `进入Brief`、`本周做`、`暂存` 或 `不做`。
4. 尽量点一个 `选择原因标签`。
5. 后续运行 `python3 scripts/learn_from_topic_selection.py --mark-pending-confirm`，生成选择学习摘要并标记为 `待确认学习`。
6. 你确认摘要正确后，再运行 `python3 scripts/learn_from_topic_selection.py --approve-latest --mark-learned`，学习结果才会进入下一轮主编判断。

## 当前边界

飞书 API 已能创建画册和看板视图，也能创建选择反馈字段，并能写入 `卡片速读`。但飞书 OpenAPI 当前不支持修改画册/看板视图的卡片展示字段；如果 `今日挑选卡片` 里仍只显示标题，需要在飞书 UI 的画册视图设置里打开这些卡片字段：

- `卡片速读`
- `状态`
- `选择原因标签`
- `人工一句话判断`

原生自动化规则本身是否能通过开放 API 创建，当前未在项目内稳定接入；因此 v0.3 先把字段、视图和学习脚本准备好。需要自动触发时，优先用飞书 UI 配置：

- 当 `状态` 改为 `进入Brief / 本周做 / 暂存 / 不做`，把 `学习状态` 设为 `待学习`。
- 当 `状态` 改为 `进入Brief / 本周做`，由本机轻量 watcher 扫描近 5 天待生成队列并按需运行 `codex_script_package_runner.py --write-feishu --limit 2 --max-age-days 5` 生成 `06 完整脚本与制作包`；急用时可手动运行同一命令。
