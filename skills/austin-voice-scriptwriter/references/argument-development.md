# 论点发展参考

这是一组写作前的内部追问，不是正文提纲，也没有规定使用顺序。当前题目不需要的追问可以放下。

- 大多数人看到这条热点，最容易得出什么结论？这个结论漏掉了哪一个具体问题？
- 哪些当前事实真的支撑这个问题，哪些只是标题、情绪或联想？
- 变化通过什么中间机制影响工作、产品或业务？中间哪一步最容易被误读？
- 谁会因此得到时间、能力或机会，谁会承担新的成本、风险或判断压力？
- 最强的反方意见是什么？这个判断在哪些条件下不成立？
- 站在 Austin 已有业务位置上，哪一句中心判断是当前证据和经验共同能负责的，而且换一个热点不能原样搬走？

写作者可以先在内部形成自己的判断，再自由决定正文从现场、事实、问题、故事或结论进入。不要把这些问题变成可见小标题、固定段落或质量计分。
