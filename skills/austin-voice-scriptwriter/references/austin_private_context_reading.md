# Austin Private Context Reading Contract

This is a reading contract, not a public style summary and not a source of current topic facts.

After a complete facts-first draft exists for a topic, the current outer Codex may directly read the allowlisted excerpts below through this Skill for one Austin Author Edit. The actual excerpt text is transient writer context. The Python runtime only verifies availability and records safe provenance; it does not replace the reading with hashes or abstract deltas. These excerpts are never a source for the current topic's facts, opening, argument movement or close.

## Allowlist

Use `config/web010_austin_private_context_allowlist.json` as the canonical safe list. Resolve its `path_env` values in the current workspace/runtime. Read only the listed excerpts:

- `austin-persona-context`: user positioning, published voice, opening examples.
- `austin-original-private-cases`: the original case anchors and style rules in `private_runtime.json`.
- `austin-original-case-cards`: the original user case cards.
- `austin-original-sample-cover` and `austin-original-sample-radar`: the user's original spoken samples.
- `austin-original-edit-pairs`: the user's explicit before/after examples in the case document.
- `austin-approved-module-mvp` and `austin-approved-module-director`: only the listed opening, argument-turn and close modules from the two explicitly approved Austin production scripts.

Read the actual text only after the current topic draft is complete and before the single Author Edit is submitted. Do not choose one reference by keyword, entity, title token, embedding or deterministic score. Let the current draft and Topic Card determine which stance, detail selection, breathing or close needs editing. The references calibrate how Austin observes and judges; they never supply current facts, customer outcomes, the opening, the argument movement or a first-person event for the current topic.

## Exclusions

Never read as writer calibration in this path: `evidence_playbook.md`, project PRD, PM/control-plane rules, production/run manuals, Task Cards, tests/fixtures, Dev/QA/Production reports, Khazix content, system-generated scripts or rejected scripts. If a mixed source is needed, read only the explicit excerpt listed above.

## Persistence boundary

Raw excerpt text may exist only in the current outer Codex context during the post-draft Author Edit. Do not copy, quote, summarize into a new field, or attach it to a packet, workflow handoff, checkpoint, database row, final script metadata, Website payload, log or public evidence. Persist only the safe allowlist/source/excerpt IDs, hashes and read status.
