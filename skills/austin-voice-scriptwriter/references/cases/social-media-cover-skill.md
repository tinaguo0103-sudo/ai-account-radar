# 案例：Social Media Cover 封面自动化 Skill

来源：`00_资料库/04_案例库/我的案例库.docx`，第 3 题案例“Social Media Cover封面自动化Skill”。

短视频封面、小红书封面和公众号封面看起来是小活，但每次都要人工理解脚本、提炼标题、找画面、排版和校对，长期会消耗大量内容制作时间。

Austin 把封面制作拆成一个 Skill：先从脚本提炼主标题和正文，再匹配虚拟个人形象动作，最后输出适配抖音、小红书和微信公众号比例的封面。AI 负责脚本理解、视觉方向、底图和候选；Pillow 负责文字渲染和固定安全区；最终还要检查文字、比例、版式和风格一致性。

案例结果是封面从一次次手工处理变成可自动化、可复用、可批量输出的内容资产。它不能证明当前题目需要封面，也不能把其中的平台比例、人物或结果移植给其他项目。
